## 목표

MVP 범위를 정하기 위한 시장 조사. 전봇대 과외 전단지를 대체하는 대구 수성구 과외 매칭 서비스에서 무엇을 빼고 무엇을 꼭 넣을지 판단할 근거를 모은다.

## 완료 조건

- [x] 기존 서비스 비교 (최소 김과외, 숨고, 과외바다, 당근 + 찾아낸 것): 누가 먼저 글을 올리나(선생님 프로필 vs 학부모 요청), 연락 방식(연락처 공개·앱 내 채팅·유료 열람), 수익 모델과 수수료, 선생님 인증(학력·신원·과외교습자 신고), 후기·평점, 지역 검색 단위. 표 하나로.
- [x] 전단지 과외의 실태: 전단지에 보통 적히는 정보(과목·학년·학력·가격·연락처 등), 학부모가 전단지·지인 소개를 쓰는 이유, 기존 앱의 불만점. 출처 있는 것 위주.
- [x] 수성구 맥락: 학원가(범어·만촌·황금 등), 학생 수나 사교육 수요를 보여주는 공개 자료가 있으면.
- [x] 시사점: MVP에 꼭 필요한 것 / 빼도 되는 것 / 차별점 후보를 각 3~5줄.
- [x] 모든 사실에 출처 URL. 확인 못 한 건 "미확인"으로 표시하고 추정과 구분.

## 재작업 (오케스트레이터 검토)

출처 대부분이 사이트 첫 페이지(imaeil.com, orbi.kr, data.go.kr, suseong.kr, kihoilbo.co.kr, lawtalknews.co.kr, easylaw.go.kr, yeongnam.com 등)라 주장을 확인할 수 없다. 오케스트레이터가 일부를 검색으로 대조한 결과:

- 김과외 "첫 달 과외비 25%": 확인 안 됨. 문서 전체에서 핵심 불만으로 반복되므로 출처를 찾거나 "미확인"으로 바꾸고, 그 주장에 기댄 문장도 고친다.
- 숨고: 공식 고수 안내(https://soomgo.com/pro)는 "고객이 견적을 열람했을 때만 과금, 48시간 미열람 시 보너스캐시로 환급". 금액(1,500~3,500원)과 "매칭 여부 무관" 설명을 이 기준으로 고친다.

할 일:
- [x] 구체적인 사실·숫자마다 그 내용이 실제로 적힌 페이지 URL(기사·게시글·통계표 주소)을 단다. 첫 페이지 주소는 출처로 인정하지 않는다.
