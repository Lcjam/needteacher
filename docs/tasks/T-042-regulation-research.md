## 목표

과외 매칭 MVP의 범위를 바꿀 수 있는 한국 법·규제 제약을 정리한다. 구현할 때 "이건 처음부터 넣어야 한다"와 "이 기능을 넣으면 의무가 생긴다"를 가르는 것이 목적이다.

## 완료 조건

- [x] 학원법(학원의 설립·운영 및 과외교습에 관한 법률): 개인과외교습자 신고 의무, 신고번호·교습비 표시 의무, 대구시교육청 기준. 플랫폼이 신고 여부를 확인·표시해야 하는지, 대학생 과외는 어떻게 다른지.
- [x] 개인정보보호법: 만 14세 미만 가입 시 법정대리인 동의, 학생 정보를 학부모가 올리는 경우, 선생님 학력·신원 증빙 보관, 연락처 노출 방식별 위험.
- [x] 결제·중개: 수수료를 받거나 결제를 중개하면 생기는 의무 (전자상거래법 통신판매중개자, PG 계약 등). 결제를 넣지 않으면 피할 수 있는지.
- [x] 위치 정보: 동 단위 지역 선택만 하면 위치정보법 대상이 아닌지, GPS를 쓰면 무엇이 생기는지.
- [x] 위 항목마다 "MVP에 미치는 영향" 한 줄: 필수 기능 / 해당 기능을 넣으면 생기는 의무 / 무관.
- [x] 법령·고시는 조문이나 출처 URL. 확인 못 한 건 "미확인"으로 표시. 웹 검색이 안 되면 그 사실을 결과에 적고, 아는 범위만 "미확인" 표시로 쓴다.
